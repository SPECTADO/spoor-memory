# Architecture decision records

Project decisions, MADR style, each with date and deciders. Template and rules: the `adr` skill. Never rewrite an accepted ADR; supersede it with a new one. Design sources are in [docs/design](../design/); deviation ids (D1-D9, I1-I45, G, H, P3) are defined in [deviations.md](../design/deviations.md). All ADRs 0001 to 0014 are accepted; 0021 to 0023 and 0025 are proposed and wait for the owner. Where the amendments in BRIEF.md changed an earlier choice (D9, I33 to I38), the ADR text already states the amended rule. How the decisions show up for users: [user-guide.md](../user-guide.md), [agent-guide.md](../agent-guide.md), [operations.md](../operations.md).
