## Rejected sub-parts (summary)

1. L2: promoting an observation on a near-duplicate hit. Creating the new item is simpler and keeps both claims.
2. L3: a whole-item (mean-of-chunks) vector for doc dedupe. It would need an item-level vector per model; `allow_duplicate` covers the false positive.
3. A7: fetching tier 4 on the first `UserPromptSubmit`. It adds a fourth hook the brief does not list; the agent can pass a query to `spoor_context` itself.
4. A13: skipping the nag below two changed files. It would contradict BRIEF ("blocks once, only when the session changed files and made no Spoor writes") and DoD 3.
